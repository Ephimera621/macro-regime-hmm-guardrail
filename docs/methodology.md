# Methodology

## 1. 연구 설계

본 연구는 거시·시장 변수에서 잠재적인 금융 스트레스 국면을 추정하고, 그 정보를 정적 분산 포트폴리오의 위험관리 신호로 사용하는 방법을 평가합니다.

모델의 목적은 다음 날의 수익률을 예측하는 것이 아닙니다. 느리게 변화하는 거시·금융 취약성을 확률로 요약하고, 위험이 충분히 높고 지속적일 때만 포트폴리오를 방어적으로 전환하는 것입니다.

## 3. 경제축

원 변수를 그대로 HMM에 모두 투입하지 않고, 경제적 방향을 맞춘 expanding z-score 기반 축을 구성했습니다.

- `InflationPressure`: CPI, 기대인플레이션, 원자재·금 관련 변수
- `GrowthWeakness`: 실업률, 고용, 산업생산 및 위험자산 모멘텀
- `FinancialStress`: VIX, 실현변동성, 금융여건 및 자산 간 분산
- `PolicyTightness`: 실질금리, 단기·장기금리, 기간스프레드, 달러
- `TransitionInstability`: 국면 전환 가능성을 보조하는 불안정성 축

거시 데이터는 발표 지연과 실제 사용 가능 시점을 근사 반영했습니다. 다만 최초 발표치 전체를 복원하는 완전한 ALFRED vintage 설계는 아닙니다.

## 4. HMM

초기 연구는 3-state Gaussian HMM을 사용했지만, 두 개의 저위험 상태가 경제적으로 충분히 구분되지 않고 상태 전환이 과도하게 발생했습니다. 정보기준과 walk-forward 선택 결과도 2-state를 지지해 최종 모델을 다음과 같이 단순화했습니다.

- Lower-stress state
- Higher-stress state

포트폴리오 신호에는 hard label보다 `P(stress | information available at t)`를 사용합니다.

## 5. OOS 설계

- 초기 학습 종료: 2012-12-31
- OOS 시작: 2013-01-01
- expanding-window 학습
- 미래 데이터가 학습 구간에 포함되지 않도록 fold 분리
- 거래 실행 지연 및 거래비용 반영

분기 재학습은 posterior jump를 크게 만들었고, 고정 모델은 안정적이지만 지나치게 오래된 상태를 유지했습니다. 연간 재학습을 두 극단 사이의 실용적인 절충안으로 채택했습니다.

## 6. Hysteresis guardrail

기준 설정은 다음과 같습니다.

- 스트레스 진입: `p_stress >= 0.70`이 5거래일 지속
- 스트레스 해제: `p_stress <= 0.40`이 10거래일 지속
- 포트폴리오 리밸런싱: 분기
- 기본 거래비용: turnover 기준 2bp

서로 다른 진입·해제 임계값과 확인 기간은 하루 단위의 확률 노이즈가 잦은 매매로 전달되는 것을 줄입니다.

## 7. Drift-aware accounting

정적 포트폴리오도 리밸런싱 사이에 실제 비중이 변합니다. 따라서 목표 비중 차이만으로 turnover를 계산하지 않고, 자산 수익률로 변화한 보유 비중을 다음 리밸런싱 시점의 거래 전 비중으로 사용했습니다.

최종 가드레일과 비교하는 핵심 벤치마크는 같은 분기 주기의 정적 분산 포트폴리오입니다.

## 8. 사전 정의된 통과 조건

- Max Drawdown 개선 > 0
- Calmar 변화 > 0
- CAGR 감소가 -0.75%p 이상

이 기준은 CAGR을 극대화하는 전략 선택이 아니라, 제한된 수익 희생으로 손실 위험을 줄이는 가드레일의 목적에 맞춰 정의했습니다.
