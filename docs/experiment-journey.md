# Experiment Journey

전체 연구는 34개의 단계로 진행됐지만, 최종 결론에 직접 연결되는 전환점만 정리합니다.

## 1. 탐색적 국면 판별

자산 수익률과 거시·시장 변수를 활용해 2~4 state HMM을 탐색했습니다. 초기에는 성장, 전환, 위기처럼 세분된 3-state 구조를 기대했습니다.

## 2. 3-state 모델의 실패

진단 결과 3-state 모델은 두 개의 저위험 상태를 불안정하게 분할했습니다.

- 지나치게 많은 raw state flip
- 유사한 저위험 상태의 반복 전환
- 경제적 해석력 저하
- 정보기준과 walk-forward 선택에서 2-state 우세

복잡한 상태 수가 반드시 더 많은 경제적 정보를 의미하지 않는다는 점을 확인했습니다.

## 3. Canonical 2-state HMM

모델을 정상/스트레스의 2-state 구조로 단순화했습니다. 상태 평균과 전이행렬의 해석이 명확해지고 지속성도 개선됐습니다.

## 4. Direct allocation 실패

스트레스 posterior를 매일 포트폴리오 비중에 직접 연결했습니다. 그러나 OOS에서 다음 문제가 나타났습니다.

- 재학습 경계에서 posterior 급변
- 국면 분류를 자산 기대수익 예측으로 과도하게 확장
- 높은 turnover
- 정적 분산 포트폴리오 대비 불안정한 성과

따라서 HMM을 독립적인 allocation engine으로 사용하는 가설을 기각했습니다.

## 5. 실패 원인 진단

고정, 연간, 분기 expanding 재학습을 비교했습니다.

- 고정 모델: 안정적이지만 새로운 환경 반영이 부족
- 분기 재학습: posterior 불안정성이 큼
- 연간 재학습: 안정성과 적응성의 절충

## 6. Guardrail 전환

HMM의 역할을 수익 예측에서 위험 개입으로 축소했습니다.

```text
HMM posterior
→ hysteresis confirmation
→ low-frequency stress flag
→ base/stress portfolio selection
→ quarterly execution
```

## 7. 공정한 벤치마크

목표 비중 차이만 계산하던 기존 회전율 측정을 실제 보유 비중 drift를 반영하도록 수정했습니다. 최종 비교는 같은 분기 리밸런싱 정책을 사용하는 정적 포트폴리오와 수행했습니다.

## 8. 강건성 검증

### Base allocation

방어형부터 공격형까지 다섯 개 기준 포트폴리오에서 검증했습니다. 모든 포트폴리오에서 사전 정의한 가드레일 조건을 통과했습니다.

### Threshold and cost

진입 임계값 3개, 해제 임계값 3개, 거래비용 4개, 기준 포트폴리오 5개의 180개 조합을 평가했습니다.

### No-TED

LIBOR 전환 이후 중단된 TEDRATE가 forward-fill돼 Financial Stress 축에 남는 문제를 발견했습니다. 해당 변수를 제거하고 전체 검증을 다시 수행했으며 pass/fail 결정은 180개 중 하나도 바뀌지 않았습니다.

### DAG allocation

Stage 17~20의 그래프 및 DML 결과에 강한 인과 가정을 부여해 자산배분에 사용했습니다. 이 보조 실험도 HMM 가드레일을 대체하지 못했습니다. 따라서 DAG는 설명·진단 계층으로만 해석합니다.

## 최종 연구 위치

본 프로젝트는 고수익 알파 발견 연구가 아닙니다.

> 거시 HMM은 noisy하며 직접 배분에 과도하게 사용하면 안 된다. 가장 방어 가능한 용도는 정적 분산 포트폴리오에 제한적으로 개입하는 저빈도 손실방어 가드레일이다.
